# Dexter Store — โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ (มีแค่ตัวหน้า + เรียกไฟล์ css/js)
css/style.css         ธีมและหน้าตาทั้งหมด
js/core.js            ตัวช่วย, ข้อมูลร้าน (localStorage), session, ธีม, header/nav, modal
js/auth.js            สมัคร / เข้าสู่ระบบ / ยืนยันไม่ใช่บอท
js/shop.js            หน้าแรก, แบนเนอร์, สินค้า, ซื้อ, เติมเงิน
js/profile.js         โปรไฟล์, ประวัติ, ตัวกรองวัน
js/admin.js           หลังบ้านทั้งหมด (สินค้า+สต็อก, หมวด, สมาชิก/ยศ, ระบบรับเงิน, ตั้งค่า)
js/main.js            เริ่มทำงาน
server/               เซิร์ฟเวอร์รับซองทรูมันนี่ (Node.js 18+) แยกต่างหาก
```

- ลำดับโหลดใน index.html สำคัญ (core → auth → shop → profile → admin → main) ห้ามสลับ
- เปิด index.html ได้เลย ไม่ต้องติดตั้งอะไร
- ขึ้นโฮสต์: อัปโหลดทั้งโฟลเดอร์ (ยกเว้น server/) ไปที่ Netlify / Cloudflare Pages / GitHub Pages
- เข้าหลังบ้าน: กด "เข้าสู่ระบบ" แล้วใส่รหัสแอดมิน (เริ่มต้น admin1234 เปลี่ยนที่ ตั้งค่าเว็บ)
